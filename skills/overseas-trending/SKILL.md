# 海外跨平台热文搜索

输入任意关键词（中文/英文），一键搜索 X / TikTok / YouTube 三平台热门内容，每平台按排序指标取 Top N（默认 5），输出统一字段列表。

> API 请求均携带 `ChinaTrendingDigest-dsh` 标识，X-API-KEY 鉴权。

## 数据口径

- **统一记录 schema**：platform / title / url / author / likes / comments / views / shares / publish_time / keyword / lang。
- **TikTok**：searchVideo 一次请求自带全部互动数据（接口 2026-11 已变更，需 offset+count 参数，插件已适配）。
- **X**：search 必填 `searchType=Top`（缺失会误报 3203）。
- **YouTube**：searchVideo 只返回播放数与相对发布时间，点赞/评论由 videoDetail 逐条补全（默认补 20 条，`detailTop` 可调小省积分；分享数 YouTube 不公开恒为 0）。
- **语言优先分层**：中文关键词各平台组内优先中文内容、英文关键词优先英文内容，其他语言兜底；层内按排序指标降序。语言识别基于标题字符集（汉字/假名/谚文/拉丁）。
- **时间窗口**：默认最近 1 天；TikTok 热门多为历史内容，会被窗口整体过滤（回执注明排除数）——看 TikTok 热门请放宽 days 到 3-7 或 0。

## 积分纪律

- YouTube 详情补全是消耗大头（每关键词最多 20 次 videoDetail）。一次三平台搜索约 23+ 次接口调用。
- 不要主动重复搜索；用户没明确要求不跑多个关键词组合。
- 平台故障（3203）优雅降级：故障平台在结果前如实标注，不影响其他平台结果，不编造条目。

## 展示规范

向用户展示时必须包含：平台、标题（前 20 字）、作者、播放数、点赞数、评论数、发布时间（YYYY-MM-DD HH:mm）、链接（内联可点击）。数值千/万简写。平台状态在结果前明示。数值来自数据服务，严禁编造。

## 跨平台对比解读（由 agent 完成）

- 同一关键词对比三平台的热度与内容形态差异（X 偏观点讨论、TikTok 偏短视频传播、YouTube 偏深度内容）。
- 语言分层结果可用于判断话题在不同语言市场的渗透度。
- 引用一律内联链接；末尾逐字附上工具返回的页脚。

## 面板

- 侧栏「海外跨平台热文搜索」面板：搜索表单（关键词/平台多选/时间窗口/排序/每平台条数）、历史归档、交互式 HTML 报告（卡片/表格双视图切换、平台状态展示）。
